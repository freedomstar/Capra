Capra: PS Remote Privacy Policy
Updated: 2026-11-14

This policy applies to the Capra Android app. Capra is an independent PS5 streaming client and is not affiliated with Sony.
Developer: hikaru
Privacy and support email: 1810834604@qq.com
Public policy URL: https://freedomstar.github.io/Capra/

1. Data processed and its purpose
• PSN sign-in takes place on Sony's HTTPS sign-in page. Credentials are submitted by that page to Sony; Capra's native code does not read or store your PSN password. The app temporarily handles an authorization code and access token to obtain the Account ID and Online ID needed for pairing. Codes and tokens are not written to preferences or exported presets. Account identifiers are stored locally.
• Console discovery, manual setup and pairing process console names, addresses, identifiers and pairing keys to discover, wake and connect to the PS5 you select.
• Streaming sends video and audio from the connected PS5 to this device, and sends touch, controller and supported motion input to that console. Capra does not provide gameplay recording or cloud storage.
• Video preferences, controller mappings, touch layouts, language, launcher entries and connection presets are stored locally. Remembered console sign-in PINs are encrypted using Android Keystore-backed keys. Other local data is protected by Android's app sandbox.
• Diagnostics: the app creates local connection and error logs that may contain console addresses, device and session diagnostic information. Performance displays and diagnostic records help investigate issues. Logs are not automatically uploaded to the Capra developer. Review logs before sharing them.

2. Transfers and third parties
PSN sign-in and account lookup communicate with Sony services. Console discovery and streaming communicate with the selected PS5. Network connections expose the IP addresses needed for communication to the other party. Sony's processing is governed by its own privacy policy. Manual WAN connections require reachable addresses, port forwarding or a configured VPN; Capra does not provide a cloud relay or VPN service.
The release build has no Capra account system, advertising SDK or usage analytics SDK, and does not automatically upload accounts, gameplay or diagnostic data to a developer server. Personal data is not sold. Content that you explicitly share or export through another app is handled under that service's policies.

3. Retention and deletion
Account identifiers, pairing data and preferences remain on this device until overwritten, removed or cleared. Remembered console sign-in PINs can be cleared in settings. To delete all local account identifiers, pairing data, preferences and logs, use Android Settings → Apps → Capra → Storage → Clear data, or uninstall the app. Existing pairings will be lost and setup will be required again.
When the PSN sign-in screen closes, the app requests deletion of temporary WebView cookies, cache and web storage. Connection logs rotate when new logs are created; Android may clear diagnostic caches. Android automatic backup is disabled. Manually exported or shared copies must be deleted separately from their destinations. Clearing Capra data does not delete your Sony account or data held by Sony.

4. Permissions and security
Network access is used for sign-in, discovery and streaming; network state for connection handling; vibration for game feedback; and high-rate sensor access for supported motion input. This version does not request contacts, location, camera or microphone permissions. Sony authorization requests use HTTPS with certificate validation; streaming uses the integrated Remote Play protocol. Connect only to consoles you are authorized to use.

5. Updates and contact
This policy and its date will be updated when data handling changes. For questions about this policy or data handling, contact 1810834604@qq.com. The developer is hikaru.

Debug test ads: Debug builds alone include the Google AdMob SDK and use Google-provided sample app and ad unit IDs. Requesting a test ad on the home or connection waiting screen contacts Google services and may involve IP addresses, device identifiers, and SDK diagnostics or interaction data. Test ads generate no advertising revenue. No in-app purchases are integrated. Google privacy policy: https://policies.google.com/privacy .

Capra: PS Remote 隐私政策
更新日期：2026-11-14

本政策适用于 Capra Android 应用。Capra 是独立的 PS5 串流客户端，与 Sony 无隶属关系。
开发者：hikaru
隐私与支持邮箱：1810834604@qq.com
本政策公开网址：https://freedomstar.github.io/Capra/

1. 处理哪些数据、用于什么目的
• PSN 登录：通过 Sony 的 HTTPS 登录页面进行。登录凭据由该页面提交给 Sony，Capra 的原生代码不读取或保存 PSN 密码。应用临时处理授权码和访问令牌，以获取配对所需的 Account ID 与 Online ID。授权码及令牌不写入偏好或预设导出；账号标识保存在本机。
• 主机与配对：局域网发现、手动输入和配对会处理主机名称、地址、标识及配对密钥，用于发现、唤醒和连接你选择的 PS5。
• 串流：视频和音频从所连接的 PS5 传至本设备，触屏、手柄及支持的运动输入传至该主机。Capra 不提供游戏画面录制或云端存储服务。
• 偏好：画质、手柄映射、触屏布局、语言、桌面入口及连接预设保存在本机。选择记住的主机登录 PIN 使用 Android Keystore 支持的加密保存；其他本地数据受 Android 应用沙箱保护。
• 诊断：应用在本机生成连接和错误日志，可能包含主机地址、设备及会话诊断信息；性能显示和诊断记录用于排查问题。日志不自动上传给 Capra 开发者。分享日志前应检查其内容。

2. 数据传输和第三方
PSN 登录和账号查询与 Sony 服务通信；主机发现及串流与所选 PS5 通信。网络连接会向通信对方暴露连接所需的 IP 地址。Sony 对其服务中的数据处理适用其自身的隐私政策。手动外网连接需使用可达地址、端口转发或已配置的 VPN；Capra 不提供云端中继或 VPN 服务。
正式版没有 Capra 账号系统、广告 SDK、使用行为分析 SDK，也不向开发者服务器自动上传账号、游戏内容或诊断数据。不出售个人数据。你主动通过其他应用分享或导出的内容由所选服务按其政策处理。

3. 保存与删除
账号标识、配对和设置保存在本设备，直到被覆盖、移除或清除应用数据。可在设置中清除记住的主机登录 PIN。要删除全部本地账号标识、配对、设置与日志，可使用 Android 系统「设置 → 应用 → Capra → 存储 → 清除数据」，或卸载应用；这会使现有配对失效，需要重新配置。
PSN 登录页退出时会请求清除临时 WebView Cookie、缓存和网页存储。连接日志在创建新日志时轮换，诊断缓存可被系统清理。应用禁用 Android 自动备份；手动导出或分享的副本需在保存位置另行删除。清除 Capra 数据不会删除 Sony 账号或 Sony 保存的数据。

4. 权限与安全
网络权限用于登录、发现与串流；网络状态用于连接处理；振动用于游戏反馈；高频传感器访问用于支持的运动输入。本版本不申请通讯录、定位、相机或麦克风权限。Sony 授权请求使用 HTTPS 并校验证书；串流使用所接入的 Remote Play 协议。请只连接你有权使用的主机。

5. 政策更新与联系
数据处理方式变化时将更新本政策及日期。如对本政策或数据处理有疑问，请联系 1810834604@qq.com。开发者为 hikaru。

调试版测试广告：仅 Debug 构建接入 Google AdMob SDK，并使用 Google 官方测试应用和广告单元 ID。首页或连接等待页请求测试广告时会与 Google 服务通信，可能涉及 IP 地址、设备标识及 SDK 诊断或交互数据；测试广告不产生广告收入。调试版不接入内购。Google 隐私政策：https://policies.google.com/privacy 。
